#Fixie

## Main Features ##
scan: Take photos of trash/junk and using an AI model to learn what it is for accuracy.\
Results: Showcase proper ways of trashing/recycling and give ideas on ways to repurpose said junk.\
Grove: As you upload more and more your "Grove" grows becomimg more and more Foliage dense.\
Streak: gamifying the process and promoting daily use by givinf players a satisfying display of their "streak" of recycling
    this streak can make your "Grove" look more magical

## Running ##
use 'pnpm install' for dependecies\
then 'pnpm dev' for local host point
